# Quack Cook

- กด F5 เพื่อเปิดเมนูหลัก: `scenes/ui/main_menu.tscn`
- เปิด `scenes/main.tscn` แล้วกด F6 เพื่อทดสอบครัวโดยตรง
- คู่มือโครงสร้างและตำแหน่งไฟล์: [docs/project_structure.md](docs/project_structure.md)
- วิธีทดสอบระบบเดิม: [docs/testing/](docs/testing/)

Autoload มี `GameManager` และ `QueueManager` อยู่ใน `scripts/managers/`
